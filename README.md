# microzed-linux

Private repo used with Claude Code sessions. Two uses (see `CLAUDE.md`):

1. General questions from a phone (no files). Saved notes go in `notes/`.
2. Learning embedded Linux and FPGA on an Avnet MicroZed (Zynq-7010).

## MicroZed project

- `buildroot-microzed-project.md`: start here. Board, Buildroot setup, current state, results of every project, open problems, next steps, lessons learned.
- `microzed/`: all sources (kernel modules, programs, Buildroot packages, rootfs overlay, FPGA designs, laptop tools). See `microzed/README.md`.
- `microzed/projects/`: one brief per project, 01 to 08 done. See `microzed/projects/README.md`.
